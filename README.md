# Nooby's uh modded reanimation v1.1.1

> "Leave the past and live in the future."

A heavily customised fork of **Uhhhhhh** by **STEVETHEREALONE**.

This is not a light reskin. It’s a full experience overhaul with cinematic intros, modern glass UI, performance tools, and a ton of quality-of-life systems while keeping the original reanimation core intact.

### What’s new / improved

**Cinematic Intros**
- Multiple selectable intros locked to real songs (Moonlight, Jealousy, Lil Peep, Liquid Smooth, Thriller, Perfect Face, The Aura Farmer, Survivor, Paparazzi, Baby One More Time, and more)
- Audio-reactive, beat-synced, full cinematic treatment

**UI & Polish**
- Glass / bubbly UI with 3D buttons, register-lock motion, dock system
- Dynamic colour system (7 accent modes + 5 harmonies + visual colour picker)
- Feature search bar that finds almost every option
- Low End UI Mode for weaker devices
- Animated moveset/dance previews
- Customization page packed with options

**Reanimation**
- Improved hat methods including Nooby’s experimental method
- “Under ReanimCharacter (Keep Streamed)” respawn option
- Limb reanimation + compatibility checker
- Better stability and less hat drop in many cases

**Systems**
- Full Nameless Admin runtime embedded (uses `.` prefix so it doesn’t clash)
- Performance section (Anti Lag, Hide All Players, adaptive profiles)
- Auto FPS governor
- Delta customizer / fast execute options
- Moveset & Dance marketplace + Nooby’s unofficial store
- Script Hub, plugins, fling methods, server hop, etc.

---

### How to use

1. Use a supported executor (Delta is especially well supported)
2. Execute the script
3. Let the intro play or skip it
4. Open the UI with the triangle / command system
5. Pick your reanimator mode, moveset, dances, and settings

Recommended: turn on **Low End UI Mode** if you’re on a low-end device or mobile.
